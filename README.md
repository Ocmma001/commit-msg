# commit-msg

在 Codex 中自动结合当前对话上下文与 Git 改动生成准确的提交说明；明确要求提交时，执行范围清楚的本地提交。

## 安装与使用

1. 使用 Codex，并确保目标项目是 Git 仓库。
2. 将整个文件夹命名为 `commit-msg`，放进 Codex 的技能目录，保留内部相对路径。
3. 在目标项目的对话中说：`用 commit-msg 为已暂存的改动写提交说明`。

默认只生成说明，不暂存、不提交、不推送。需要执行提交时，明确说“把这些改动提交”。

必须能运行 Git。辅助脚本使用 Python 3.10+ 和标准库，无第三方依赖；没有 Python 时，Codex 仍可使用原生 Git 完成任务。无须配置本技能专用的 API 密钥或个人路径。

## 自动使用当前上下文

调用技能后，Codex 自动利用当前可见的对话、已提供的上下文摘要及你附加的材料，提取这次改动的目标、原因和提交范围，再结合实际 Git 改动撰写说明。无须导出聊天、提供记录文件或运行对话检索命令。

技能不会扫描本地会话日志或其他项目的聊天，也不会把私人对话上传到 GitHub。`scripts/collect.py` 只采集 Git 证据。

当前上下文不等于完整历史：已经不在上下文中的旧消息不会被自动恢复。缺少原因时根据代码客观描述；仅当缺失信息影响提交范围或授权时再询问。讨论过但尚未实现的计划不会写成已完成的功能。
